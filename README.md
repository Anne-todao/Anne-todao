### 👩‍💻 Sobre Mim

> Sou desenvolvedora focada no ecossistema **Front-end**, apaixonada por transformar ideias visuais em aplicações funcionais, rápidas e acessíveis.

- 🔭 **Foco Atual:** Criação de aplicações web modernas e responsivas utilizando **React** e **JavaScript**.
- 🌱 **Evolução Contínua:** Aprofundando conhecimentos em arquitetura de componentes e boas práticas de código.
- 💡 **Interesses:** UI/UX Design, acessibilidade na web e otimização de performance.
- 🎯 **Objetivos:** Fazer parte de projetos desafiadores e criar experiências incríveis para os usuários.
